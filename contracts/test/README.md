# Contract tests

Foundry tests for the contracts in `src/`. Run them from `contracts/`:

```bash
forge test        # everything
forge test -vv    # with logs, as CI runs it
forge test --match-contract StopTest
```

| File | Contracts | What it checks | Why |
| - | - | - | - |
| `Base.t.sol` | (helpers) | Deploys the whole system and drives a project through its life | Every suite starts from the same real deployment |
| `Flows.t.sol` | (helpers) | Walks a milestone through its states the way the backend does | Tests read like the flows they protect |
| `Core.t.sol` | `VAZNTest`, `HubTest`, `FactoryTest` | vAZN minting and burning only by the ledger and vault, roles, 48-hour key changes, the release pause, launching escrows | No one, Veritas included, can move money outside the rules |
| `Ledger.t.sol` | `LedgerTest`, `ReceiptTest` | Bank-signed batches, credits, attestations that freeze releases, receipts, key rotation and refusals | Donations on-chain match the bank, and a donor's receipt is theirs |
| `Milestone.t.sol` | `MilestoneFlowTest`, `VotingTest` | A whole milestone, release conditions, failed payouts, overrides, resubmission, votes and turnout | "No release without approval" holds in code |
| `Stop.t.sol` | `StopTest`, `AllocationTest` | Withdrawals, refunds, redirects, defaults, payouts in flight, leftovers | A stopped project gives every donor's money back or moves it on |
| `Fuzz.t.sol` | `ClaimFuzzTest` | Claims for random amounts and spends | Money cannot be claimed twice or out of thin air |
| `PythonSigned.t.sol` | `PythonSignedTest` | A project's life with every signature, root and proof made by the Python backend | The backend and the contracts agree on every signed byte |

`fixtures/PythonVectors.sol` is generated by `backend/scripts/make_contract_vectors.py`; do not edit
it by hand.
